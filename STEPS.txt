=====================================================================
 الجزء (أ): تحديث مستودعك الحالي بالنسخة الجديدة
            (استخدمه الآن، المستودع موجود والأسرار مضافة)
=====================================================================

1) افتح https://github.com/Dev-saged/SMS-Barq

2) ارفع الملف المضغوط الجديد كما هو:
   Add file ← Upload files ← اختر Barq-project.zip ← Commit changes

3) البناء يبدأ تلقائياً. يفك الـ zip، ويستبدل الملفات بالنسخة الجديدة،
   ثم يبني التطبيق.
   ملاحظة: ملف .github/workflows/build.yml لا يتحدث من الـ zip (قيد في GitHub).
   الموجود عندك يكفي. إذا احتجت تحديثه: افتحه ← ✏️ ← الصق المحتوى الجديد ← Commit.

4) راقب: تبويب Actions ← Build Barq APK
   - دائرة صفراء = يعمل (6 إلى 10 دقائق)
   - ✅ أخضر = نجح ← اذهب للخطوة 5
   - ❌ أحمر = فشل ← اذهب للجزء (ج)

5) نزّل التطبيق:
   الصفحة الرئيسية ← Releases ← «Barq — آخر نسخة تجريبية» ← Barq-latest.apk

6) ثبّته على الجوال:
   - اسمح بالتثبيت من هذا المصدر إذا سُئلت
   - إذا ظهر تحذير Play Protect ← «التثبيت على أي حال»
   - افتح برق ← «اجعل برق تطبيق الرسائل الافتراضي» ← وافق على الأذونات


=====================================================================
 الجزء (ب): مستودع جديد من الصفر (لو احتجت تعيد كل شي)
=====================================================================

1) github.com ← + ← New repository ← الاسم مثلاً SMS-Barq
   ← فعّل Add a README ← Create repository

2) ملف البناء (مرة واحدة فقط):
   Add file ← Create new file
   الاسم بالضبط:  .github/workflows/build.yml
   (كل «/» تصنع مجلداً، وانتبه للنقطة بأول .github)
   الصق محتوى الملف Barq/.github/workflows/build.yml من الـ zip ← Commit

3) أسرار التوقيع (مرة واحدة فقط):
   Settings ← Secrets and variables ← Actions ← New repository secret
   أضف الأربعة من الملف SECRETS.txt داخل Barq-signing-keys.zip:
     KEYSTORE_BASE64          ← كل محتوى KEYSTORE_BASE64.txt
     SIGNING_STORE_PASSWORD
     SIGNING_KEY_ALIAS        ← barq
     SIGNING_KEY_PASSWORD

4) ارفع Barq-project.zip كما في الجزء (أ) خطوة 2، وكمل نفس الخطوات.


=====================================================================
 الجزء (ج): إذا فشل البناء ❌
=====================================================================

1) Actions ← اضغط على العملية الفاشلة
2) اضغط ⋯ (أعلى اليمين) ← Download log archive
   (أو افتح الخطوة الحمراء وانسخ آخر 40 سطراً)
3) في محادثة الذكاء الاصطناعي أرفق:
     - ملف الـ log (zip)
     - docs/PROJECT_CONTEXT.md
   واكتب: «هذا مشروعي برق، صار خطأ بالبناء، صلّحه وأعطني الملفات المعدّلة»
4) طبّق التصليح بإحدى طريقتين:
     - تعديل ملف واحد: افتح الملف على GitHub ← ✏️ ← الصق المحتوى الجديد ← Commit
     - تعديلات كثيرة: اطلب zip كاملاً وارفعه كما في الجزء (أ)
5) كرر حتى يظهر ✅


=====================================================================
 الجزء (د): تشغيل المشروع مع ذكاء اصطناعي آخر / محادثة جديدة
=====================================================================

1) أرفق الملفات بهذا الترتيب:
     ① docs/PROJECT_CONTEXT.md   (الأهم، فيه كل القرارات والبنية)
     ② Barq-project.zip          (إذا كان المساعد يقدر يقرأ الكود)
     ③ آخر log بناء (إن وُجد خطأ)
2) أول رسالة مقترحة:
   «هذا مشروعي تطبيق رسائل اسمه برق. اقرأ PROJECT_CONTEXT.md كاملاً والتزم
    بالقرارات فيه. أنا أشتغل من الجوال بدون حاسوب، والبناء على GitHub Actions
    في المستودع Dev-saged/SMS-Barq. المطلوب: ...»
3) اطلب منه دائماً:
     - ملفات كاملة جاهزة للصق (وليس أجزاء)، أو zip كاملاً
     - أن يحدّث PROJECT_CONTEXT.md (جدول سجل البناء) بعد كل تعديل
4) لا تعطِ أي مساعد محتوى Barq-signing-keys.zip. الأسرار موجودة في GitHub.


=====================================================================
 الجزء (هـ): إصدار نسخة رسمية بعد ما يشتغل كل شي
=====================================================================

1) عدّل gradle.properties ← VERSION_NAME=1.0.1 (مثلاً) ← Commit
2) Releases ← Draft a new release ← Tag: v1.0.1 ← Publish release
3) البناء يرفق Barq-v1.0.1-buildN.apk بالإصدار تلقائياً
   كل بناء جديد يُثبَّت فوق السابق بدون حذف، طالما الأسرار نفسها.
