# نشر «برق» وبناء ملف APK — بدون حاسوب

GitHub يبني ملف APK تلقائياً على خوادمه في كل مرة ترفع فيها تعديلاً. كل الخطوات التالية تعمل من متصفح الهاتف.

ستحتاج ملفين:
1. **`Barq-project.zip`**: المشروع كاملاً.
2. **`Barq-signing-keys.zip`**: مفتاح التوقيع الخاص بك. **لا ترفعه إلى GitHub أبداً.**

---

## الطريقة الأولى: من الهاتف (موصى بها لك)

### 1) أنشئ المستودع
1. افتح github.com وسجّل الدخول.
2. اضغط **+** ثم **New repository**.
3. الاسم: `barq`. اختر **Private** (مستحسن، ويمنحك 2000 دقيقة بناء مجانية شهرياً).
4. فعّل **Add a README file**، ثم اضغط **Create repository**.

### 2) أضف ملف البناء التلقائي (مرة واحدة فقط)
لا يستطيع GitHub إنشاء ملفات البناء من داخل ملف مضغوط، فهذا الملف الوحيد الذي تضيفه يدوياً:
1. داخل المستودع اضغط **Add file** ثم **Create new file**.
2. اكتب في خانة الاسم بالضبط: `.github/workflows/build.yml`
3. افتح `Barq-project.zip` بمدير الملفات، وادخل إلى `Barq/.github/workflows/build.yml`. انسخ كل محتواه والصقه في المحرر.
4. اضغط **Commit changes**.

> بعد هذه الخطوة ستظهر عملية في تبويب Actions تنتهي بملاحظة «المشروع لم يُرفع بعد». هذا طبيعي.

### 3) أضف مفتاح التوقيع (مرة واحدة فقط)
المفتاح يضمن أن كل تحديث جديد يُثبَّت فوق النسخة القديمة دون أن تحذفها.
1. افتح `Barq-signing-keys.zip` ثم الملف `SECRETS.txt`.
2. في المستودع اذهب إلى **Settings**، ثم **Secrets and variables**، ثم **Actions**، ثم **New repository secret**.
3. أضف الأسرار الأربعة بالأسماء والقيم المكتوبة في الملف:
   - `KEYSTORE_BASE64`: انسخ كل محتوى `KEYSTORE_BASE64.txt`، وهو سطر واحد طويل.
   - `SIGNING_STORE_PASSWORD`
   - `SIGNING_KEY_ALIAS`
   - `SIGNING_KEY_PASSWORD`

### 4) ارفع المشروع
1. في الصفحة الرئيسية للمستودع اضغط **Add file** ثم **Upload files**.
2. اختر الملف `Barq-project.zip` كما هو، بدون فك الضغط.
3. اضغط **Commit changes**.

سيفك GitHub الضغط تلقائياً، ويضع ملفات المشروع في المستودع، ثم يبني التطبيق.

### 5) نزّل التطبيق
1. افتح تبويب **Actions** وانتظر علامة ✅ الخضراء. البناء الأول يستغرق من 6 إلى 10 دقائق تقريباً.
2. لتنزيل الملف بأسهل طريقة: اذهب إلى الصفحة الرئيسية، ثم **Releases**، ثم **Barq — آخر نسخة تجريبية**، ونزّل **`Barq-latest.apk`**.
   - أو من صفحة عملية البناء في Actions، تحت قسم **Artifacts** (يصلك ملف zip وبداخله الـ APK).
3. ثبّت الملف. إذا طلب الهاتف ذلك، فعّل «السماح بالتثبيت من هذا المصدر».
4. افتح برق واضغط **«اجعل برق تطبيق الرسائل الافتراضي»**، ثم وافق على الأذونات.

---

## التحديثات لاحقاً
- **أي تعديل على ملف** (من محرر GitHub أو برفع ملفات جديدة) يبني نسخة جديدة تلقائياً، وتجدها في نفس مكان «آخر نسخة تجريبية».
- **لإصدار نسخة رسمية مرقّمة:**
  1. عدّل `VERSION_NAME` في ملف `gradle.properties`، مثلاً إلى `1.1.0`.
  2. اذهب إلى **Releases**، ثم **Draft a new release**، وفي خانة Tag اكتب `v1.1.0`، ثم اضغط **Publish release**.
  3. سيُبنى APK ويُرفق بالإصدار تلقائياً.
- **لرفع مشروع كامل محدّث** (مثلاً بعد تعديلات كبيرة): ارفع ملف zip جديد كما في الخطوة 4، وسيفكه البناء ويستبدل الملفات.

## الطريقة الثانية: من حاسوب (Git)
```bash
unzip Barq-project.zip && cd Barq
git init && git add . && git commit -m "Barq 1.0.0"
git branch -M main
git remote add origin https://github.com/<اسمك>/barq.git
git push -u origin main
```
ثم أضف الأسرار الأربعة كما في الخطوة 3. للبناء على الحاسوب مباشرة: `./gradlew assembleRelease`، ويلزم لذلك Android SDK وJDK 17.

## حل المشاكل
| المشكلة | الحل |
|---|---|
| علامة ❌ حمراء في Actions | افتح العملية، ثم الخطوة الحمراء، وانسخ آخر 30 سطراً وأرسلها لي. |
| «لم يتم تثبيت التطبيق» عند التحديث | النسخة القديمة موقّعة بمفتاح مختلف (بُنيت قبل إضافة الأسرار). احذفها مرة واحدة وثبّت الجديدة. |
| تحذير من Play Protect | طبيعي للتطبيقات المثبتة من خارج المتجر. اختر «التثبيت على أي حال». |
| عند إرسال عدد كبير من الرسائل يسأل أندرويد «السماح بإرسال عدد كبير من الرسائل؟» | هذا حماية من النظام نفسه وتظهر مرة واحدة. اختر **السماح دائماً**. |
| الرسائل المجدولة تتأخر دقائق | من الإعدادات فعّل **«السماح بالمواعيد الدقيقة»**. |
| لا تصل رسائل جديدة | تأكد أن برق هو تطبيق الرسائل الافتراضي، ويظهر تنبيه بذلك في أعلى صندوق الوارد. |

---

## تنبيهات مهمة
- **احتفظ بمفتاح التوقيع** (`barq-release.jks` وكلمة السر) في مكان آمن خارج GitHub. إذا ضاع لن تستطيع تحديث التطبيق المثبّت.
- يعمل برق دون إنترنت، ولا يرسل أي بيانات خارج الهاتف. الاستثناء الوحيد: عند تفعيل استقبال MMS، يحمّل النظام رسائل الوسائط من شبكة المشغّل.
