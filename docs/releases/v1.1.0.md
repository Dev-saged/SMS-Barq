## برق 1.1.0 — أسماء وصور جهات الاتصال

- أسماء جهات الاتصال تظهر صحيحة مهما كانت صيغة الرقم (‎059‎ أو ‎+972‎ أو ‎+970‎).
- **محادثة واحدة لكل رقم**، ودمج المحادثات المكررة القديمة تلقائياً.
- الأرقام داخل نص الرسالة تظهر بأسماء أصحابها.
- صور جهات الاتصال تظهر وتتحدث وحدها.
- **صفحة الشخص**: صورة كبيرة، الرقم بلمسة نسخ، وزر اتصال مميز.
- قائمة المحادثات أرتب: وقت بعمود ثابت وخط فاصل رفيع.
