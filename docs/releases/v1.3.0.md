## برق 1.3.0 — برق القوي

- **محرك إرسال أقوى**: عدة رسائل معاً، الرسالة اليدوية تسبق الجماعي، والتزام تلقائي بحد أندرويد حتى لا يتوقف الإرسال.
- **إعادة محاولة تلقائية** عند انقطاع التغطية أو الحد، واستكمال الإرسال بعد إغلاق التطبيق أو إعادة التشغيل.
- **شاشة «حد الإرسال»**: تشرح رفع حد أندرويد من الجوال وحده.
- متابعة ما ترسله التطبيقات الأخرى لحظة بلحظة، وإصلاح الإحصائيات القديمة.
- شاشة تفاصيل لكل إرسال جماعي: كل رقم وحالته.
- مجموعات جهات الاتصال الموجودة على الهاتف في «رسالة جديدة».
- **تفاعلات** على الرسائل، وتقارير التسليم مفعّلة افتراضياً.
- شاشة «جاهزية برق»، واجهة إنجليزية، وبحث داخل المحادثة.
